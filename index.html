Product Image Grabber

Colle l’adresse d’une page e-commerce pour récupérer les premières images des produits, les sélectionner puis créer un ZIP.

Prêt. Les sites qui autorisent l’accès depuis le navigateur peuvent être analysés directement.
Limite du mode HTML : certains sites bloquent les requêtes externes (CORS) ou chargent leurs produits uniquement après exécution de scripts. Dans ce cas, le navigateur ne peut pas les lire directement.
